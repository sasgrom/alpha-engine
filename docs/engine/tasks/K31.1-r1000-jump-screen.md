## Work

1. **Jumps (window 2019-10-01 .. 2026-10-31 first, then the rest).** For each listed move over 25% in total-return
   close, classify with stored evidence first (fable1 panel, Stooq closes already recorded, Schwab history, Tiingo,
   the Yahoo actions of the price standard, SEC split facts):
   - `split-missed`: the ratio matches a split or reverse split the adjustment did not apply → a defect; fix in the build.
   - `confirmed`: a second independent source shows the same close-to-close move on the same day (within 1%) → real.
   - `identity`: a ticker reused or a series joined across a merger/spin → cut the series at the change.
   - `single-source`: no second source → the date becomes `unusableDates` for that company (never smoothed).
   - `other`: describe it; no guessing.
   Report counts per class, in and out of the window.
2. **Companies without prices (203).** Per company: why (no ticker at the time, delisted before Tiingo/Yahoo coverage,
   class share, foreign listing, wrong ticker in K26…). Where Yahoo has a series (Yahoo is allowed; generic client, 1–2
   s a request, two retries then the todo file and skip — the collector skip rule), fetch it, check it against one
   second source on at least 20 overlapping days, and add it. Report how much member weight per quarter still has no
   prices (K31 had a maximum of 4.979%).
3. **Rebuild** the panel with the fixes as a new stamp (never overwrite `20261126T060023Z`), rerun K31's four gates, and
   write `jumps-screen.json` (one row per jump: company, date, move, class, evidence) and `no-price-companies.json`.
4. **Hand check:** 30 random `confirmed` and all `split-missed` and `identity` rows (or 30 if more) against the source
   rows; sign the review file as in K34.
